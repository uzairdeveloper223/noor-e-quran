# Noor-e-Quran

**Noor-e-Quran** is a simple and beautiful Android-based WebView app that allows users to read and listen to the Noble Qur'an online and offline.

This project is created for the sake of Allah, to spread the words of the Qur'an in an easy, accessible, and modern way — especially for those who use mobile phones frequently.

---

## Features

- Beautiful Quran UI
- Loads from optimized GitHub Pages
- Caches content for offline access
- Plays Surah/Ayah audio (with caching support)
- Fast, smooth WebView experience
- Open source for everyone to benefit
